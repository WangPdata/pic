# 淘宝图搜测试台（test-console）

本地 Web 界面，便利地批量测试 `taobao-image-search`。不改动原有任何文件，只在后台调用 `run.mjs` 并复用 `lib.mjs`。

## 启动

前置：先在项目根目录运行过一次 `./setup.sh`（安装依赖和浏览器）。

macOS / Linux：

```bash
./test-console/start.sh
```

Windows：

```cmd
test-console\start.cmd
```

浏览器打开 http://localhost:8787

## 主页：批量同款评测台 `/`

批量商品的召回率评测，核心场景。

**批量运行新搜索：**
1. 左侧勾选多张商品图片（可全选）
2. 可选填关键词、设图间间隔（防风控，默认 15 秒）
3. 点 ▶ 批量运行选中图片
4. 每个商品自动跑一次图搜，完成后生成评测卡片：左边原图，右边搜索结果图片网格
5. 看图片对比，逐条点 ✓同款 / ✗不同
6. 顶部实时统计：总商品数、找到同款、未找到同款、失败、召回率

**恢复历史：** 点"加载全部历史"可把所有跑过的结果（含标注）一次性恢复，不用重跑。页面打开时也会自动恢复。

**标注自动持久化：** 每次点 ✓/✗ 自动存到 `runs/<runId>/marks.json`，刷新、重开都不丢。

**召回率定义：** 找到同款数 ÷ 有结果商品数（找到+未找到）。失败/无结果单列，不算分母。

**每个商品价格区间：** 卡片头部显示 `¥最低 ~ ¥最高`，标注了同款还会显示 `同款中位 ¥xx`。

**筛选：** 全部 / 已找到同款 / 未找到同款 / 失败 / 未运行

**导出：** 点"导出标注"保存为 JSON。

## 离线分析 `/analyze.html`

不用启动服务，双击打开，拖入 `response.json` 即可看指标。

## 数据存放

每次运行输出在 `test-console/runs/<时间戳>/`：
- `taobao-image-search-latest-response.json` — 原始结果（分析用这个）
- `run-meta.json` — 元信息
- `marks.json` — 人工标注（持久化）
- `report.md` / `items.csv` — 报告和表格

## 指标说明

| 指标 | 含义 |
|---|---|
| 召回率 | 找到同款商品数 ÷ 有结果商品数（人工校验） |
| 找到同款 | 至少 1 条被标为 ✓ 的商品 |
| 未找到同款 | 搜到结果但没标到同款 |
| 失败 | 没搜到结果 / 运行失败 |
| 价格区间 | 该商品全部结果最低-最高 + 同款中位价 |
